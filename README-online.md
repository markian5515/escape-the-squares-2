# Онлайн-режим «Круг проти квадратів»

Онлайн-режим використовує окремий Node.js-сервер із WebSocket-з'єднанням. GitHub Pages та інший статичний хостинг обслуговують тільки клієнт; вони не запускають серверні кімнати.

## Локальний запуск

Потрібен Node.js 20 або новіший.

1. У терміналі перейдіть до папки гри.
2. Виконайте `npm install`.
3. Дозвольте локальний origin клієнта (типові адреси localhost уже дозволені) та запустіть сервер:

   ```powershell
   $env:PORT = "3000"
   npm start
   ```

4. В іншому терміналі запустіть статичний клієнт у цій папці, наприклад:

   ```powershell
   python -m http.server 8765
   ```

5. Відкрийте `http://127.0.0.1:8765/`. За порожнього `serverUrl` у [online-config.js](./online-config.js) клієнт автоматично пробує `http://127.0.0.1:3000`.

Стан кімнат зберігається в пам'яті сервера й зникає після його перезапуску. Облікові записи, хеші паролів, хмарні соло-профілі, онлайн-інвентар і серверна статистика зберігаються в `data/players.json`. Резервно копіюй цей файл на сервері, але ніколи не додавай його до репозиторію.

## Публікація

1. Опублікуйте папку гри на GitHub Pages або іншому статичному хостингу.
2. Розмістіть `server.js` як окремий Node.js-сервіс у провайдера, що підтримує постійні WebSocket-з'єднання. Використайте Node.js 20+, команду запуску `npm start` та порт із `PORT`, який надає провайдер.
3. Налаштуйте TLS/HTTPS на серверному домені й задайте `ALLOWED_ORIGINS` точним origin клієнта, наприклад `https://markian5515.github.io`. Не додавайте wildcard `*`.
4. У [online-config.js](./online-config.js) вкажіть HTTPS-адресу сервера:

   ```js
   window.GAME_CONFIG = {
     serverUrl: "https://your-online-server.example"
   };
   ```

   Клієнт перетворить HTTPS на WSS для WebSocket. Не вставляйте в цей файл секрети.
5. Перевірте `https://your-online-server.example/health`, а потім перевірте підключення двома різними браузерами/пристроями.

Не вказуйте адресу сервера в кількох файлах: `online-config.js` — єдине місце налаштування. Онлайн не буде доступний на опублікованій сторінці, доки сервер не розгорнуто та не дозволено origin.

## Онлайн-прогрес і чесність матчу

Сервер створює онлайн-профіль із нульовим онлайн-балансом, підтверджує випадковий токен і зберігає його хеш. Лише сервер нараховує онлайн-кубки після завершення матчу та записує матч за унікальним ідентифікатором, тому клієнт не може надіслати собі довільну кількість кубків або перемог. Онлайн-магазин використовує цей серверний баланс; соло-прогрес та його локальний баланс залишаються недоторканими й доступними в соло-режимі. Каталог і ціни однакові в обох режимах.

Сервер перевіряє власника кімнати, готовність гравців, допустимі команди руху, дозволені здібності та серверне перезаряджання. Він симулює рух, зіткнення, здоров'я, ворогів, кубки та раунди. При короткому розриві гравець може повернутися до кімнати протягом 25 секунд; після цього він вибуває або звільняє місце в лобі. Матчі після завершення лишаються спостережуваними до виходу гравців.

## Акаунти й хмарний соло-прогрес

Форма «Акаунт» реєструє гравця через цей Node.js-сервер. Реєстрація прив'язує поточний гостьовий онлайн-профіль до пошти, пароль зберігається лише як salted `scrypt`-хеш, а сам пароль не записується в `localStorage`. Після входу сервер повертає збережений соло-профіль (кубки, рекорд, здібності й скіни); зміни синхронізуються автоматично. Онлайн-валюта та результати матчів зберігаються окремо й залишаються серверними.

Це серверна автентифікація без підтвердження пошти чи відновлення пароля. Для публічного використання обов'язково розгорни власний сервер під HTTPS/WSS, обмеж `ALLOWED_ORIGINS`, захисти резервні копії `data/players.json` і налаштуй власний процес відновлення акаунта. Поки сервер не розгорнуто й не налаштовано в `online-config.js`, реєстрація та хмарна синхронізація недоступні.

Босові сутички, атаки гравця та особливі здібності квадратів наразі працюють у соло-режимі. Онлайн-матчі продовжують використовувати наявну авторитетну серверну симуляцію без босів; клієнт не може надсилати онлайн-нагороди.
